# Highlights

## SemDP-FL: Semantic-Sensitivity-Driven Adaptive Differential Privacy for Federated LoRA Fine-Tuning of Large Language Models

- Semantic sensitivity score fuses an LLM prior with public-proxy gradient evidence.
- Closed-form water-filling rule allocates DP budget across LoRA parameter groups.
- Noise floors on leakage-prone groups yield provable mutual-information caps.
- Up to +25.5 pp accuracy over four DP federated LoRA baselines at equal privacy.
- Head-inversion probe: embedding recovery suppressed to chance at 4.9x head noise.
